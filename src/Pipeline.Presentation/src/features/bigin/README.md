# Feature: bigin

**Owner:** @bigin-team  
**Tier (max):** T2  
**Status:** active

## Purpose
Provides an operator workspace for synchronizing Zoho Bigin organization metadata, enabled modules, active webhook notification watches, and creating protected CRM contact records across Zoho Bigin data centers.

## Commands used
- `bigin.contacts.read` (T0, read-only synchronization of contacts, org details, modules, and watch channels)
- `bigin.contacts.create` (T2, state-changing contact creation with idempotency and operator confirmation)
